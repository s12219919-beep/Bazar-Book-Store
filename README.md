# Bazar.com - Multi-tier Online Book Store

## Project Description
Bazar.com is a small online bookstore built using
a distributed microservices architecture.

## Architecture
The system consists of three independent services:

1. Frontend Service
2. Catalog Service
3. Order Service

## Technologies
- Python
- Flask
- REST APIs
- JSON
- Docker
- Docker Compose
- Git and GitHub

## Main Operations
- Search books by topic.
- Display book information.
- Purchase books.
- Update book prices and stock quantities.
